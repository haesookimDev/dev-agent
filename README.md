# Kelpie

[한국어](README.ko.md) | [English](README.en.md)

Kelpie is a self-hosted control plane for autonomous software-development agents.

Kelpie는 자율 소프트웨어 개발 에이전트를 위한 셀프 호스팅 제어 플랫폼입니다.
